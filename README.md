# 🚀 DevConf — Developer Conference Landing Page

A modern and responsive **Developer Conference Landing Page** built with **HTML5 and CSS3**. This project is designed to showcase a professional tech conference website with a clean UI, speaker profiles, pricing plans, learning tracks, and an interactive-style query section.

## 🌐 Project Overview

**DevConf** is a frontend web project created to practice and demonstrate modern **HTML & CSS layout, styling, positioning, Flexbox, typography, cards, buttons, and responsive design concepts**.

The website includes a complete conference-style landing page with multiple sections, from the hero banner and speakers to subscription plans, learning tracks, and footer navigation.

## ✨ Features

* 🎯 Modern conference landing page
* 🧭 Navigation bar with registration CTA
* 🖼️ Hero section with conference introduction
* 👨‍💻 Speaker showcase section
* 💳 Standard, Pro & Team pricing plans
* 🎥 Embedded HTML & CSS tutorial video
* 📝 Query/contact form
* 🤖 AI Engineer learning track
* ☁️ Cloud Builder learning track
* 🛡️ Security Expert learning track
* 📱 Clean and structured frontend layout
* 🎨 Custom hover effects and UI styling
* 🔤 Google Fonts integration

## 🛠️ Technologies Used

## 📌 Main Sections

### 🏠 Hero Section

Introduces the DevConf event with a headline, description, conference information, and registration button.

### 👨‍💻 Speakers

Displays conference speakers with their specialization and professional roles.

### 💰 Pricing

Includes three different plans:

* **Standard — $399**
* **Pro — $749**
* **Team — $5,999**

Each plan provides different conference benefits and access levels.

### 🎥 Learning / Video Section

Contains a video section for answering common questions and providing learning content.

### 📝 Query Section

Users can enter their name, email, select a category, and submit a question through the query form.

### 🧠 DevConf Tracks

Visitors can explore different learning paths:

* 🤖 AI Engineer
* ☁️ Cloud Builder
* 🛡️ Security Expert
